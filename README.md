# nkscape

Kauffman **NK fitness landscapes** and **NK-based agent-based models of organisations** in Python —
in the tradition of Levinthal (1997), Rivkin & Siggelkow (2003), Ethiraj & Levinthal (2004) and
Wall (2016, 2023).

> **Status: planning / pre-alpha.** Nothing usable yet. The goal is a tested, documented,
> reproducible toolkit whose every stage is validated by replicating a published figure.

## Development

```bash
uv sync
uv run pytest
uv run ruff check
uv run mypy
```
